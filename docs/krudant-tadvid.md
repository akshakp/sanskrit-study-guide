# Lesson 10 — कृदन्त and तद्धित

## Quick Definition

| Topic | Rule |
|---|---|
| **कृदन्त** | धातु + कृत्-प्रत्यय = new word |
| **तद्धित** | शब्द + तद्धित-प्रत्यय = new word |

> Lesson 10 mainly teaches **कृदन्त** with **अन** प्रत्यय.

---

# कृदन्त

## Core Rule

**धातु + अन → भाववाचक नाम**

- The new word expresses the action of the धातु.
- These words are **नपुंसकलिङ्ग**.
- They decline like **वनम्**.

### Examples

| धातु | कृदन्त |
|---|---|
| हस् | हसनम् |
| नम् | नमनम् |
| पठ् | पठनम् |
| स्मृ | स्मरणम् |
| दृश् | दर्शनम् |
| ध्यै | ध्यानम् |
| गै | गानम् |
| कृ | करणम् |
| गम् | गमनम् |
| दा | दानम् |

---

## Formation Reference

| धातु Type | Example |
|---|---|
| Normal धातु | नम् → नमनम् |
| उपधा गुण | बुध् → बोधनम् |
| ई / ऊ in उपधा | जीव् → जीवनम् |
| Consonant उपधा | रक्ष् → रक्षणम् |
| Final vowel | स्मृ → स्मरणम् |
| आदेशात्मक | दृश् → दर्शनम् |

---

## Sentence Use

A sentence can often be expressed in two ways:

### Verb Form

**अहम् ईशं स्मरामि।**

### कृदन्त + कृ

**अहम् ईशस्य स्मरणं करोमि।**

### Case Change

| Form | विभक्ति |
|---|---|
| ईशम् in **ईशं स्मरामि** | द्वितीया |
| ईशस्य in **ईशस्य स्मरणं करोमि** | षष्ठी |
| स्मरणम् | द्वितीया — कर्म of करोमि |

Another example:

**सिंहः गर्जति।**  
**सिंहः गर्जनं करोति।**

---

# तद्धित

A word formed by adding a **तद्धित-प्रत्यय** to a **शब्द** is called **तद्धित**.

**शब्द + तद्धित-प्रत्यय = तद्धित शब्द**

> Lesson 10 gives only the basic definition of तद्धित.  
> Detailed **ता / त्व** प्रत्यय are taught later.

---

## Memory Tip

**धातु → कृदन्त**  
**शब्द → तद्धित**
