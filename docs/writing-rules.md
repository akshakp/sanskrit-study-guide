# Rules of Writing in Sanskrit

## Word Order

The order of words does **not** change the meaning.

```
रामः सूर्यं नमति |
सूर्यं रामः नमति |
नमति रामः सूर्यं |
```

All are correct and have the same meaning.

---

## परसवर्ण नियम (Reciprocal Law)

This rule explains how an **anusvāra (ं)** changes before grouped consonants.

**Rule:**

- If the sound after anusvāra belongs to a consonant group → replace the anusvāra with the nasal letter of that same group
- If the following sound is not grouped → keep the anusvāra as a bindu (ं)

| Following Group | Anunāsik  | Example                |
| --------------- | --------- | ---------------------- |
| कु group        | ङ्        | शंकर → **शङ्कर**       |
| चु group        | ञ्        | संजय → **सञ्जय**       |
| टु group        | ण्        | मार्कंड → **मार्कण्ड** |
| तु group        | न्        | कंदर्प → **कन्दर्प**   |
| पु group        | म्        | अंबरीष → **अम्बरीष**   |
| Not grouped     | ं remains | संसार, हंस, संस्कार    |

---

## When a word ends in म्

| Condition             | Change                | Example                              |
| --------------------- | --------------------- | ------------------------------------ |
| Followed by Consonant | म् → Anusvāra (ं)     | रामम् नमामि = **रामं नमामि**         |
| Followed by Vowel     | म् remains (joins following vowel) | रामः भक्तम् अवति = रामः **भक्तमवति** |
| End of Sentence       | म् remains            | नमामि रामम्                          |

## Sandhi 1-3 Rule

A word ends with the **1st, 2nd, 3rd, or 4th letter** of a consonant group (क्, च्, ट्, त्, प्):

| Condition                            | Change              | Before                | After                           |
| ------------------------------------ | ------------------- | --------------------- | ------------------------------- |
| Followed by Vowel OR Ghoṣa consonant | letter → 3rd letter | स्वर्गात् अमराः       | स्वर्गा**द्** अमराः             |
| Followed by Aghoṣa consonant         | letter → 1st letter | पुरुषः ग्रन्थात् पठति | (no change)                     |
| End of Sentence                      | letter → 1st or 3rd | तरति सम्राट्          | तरति सम्रा**ट्** or सम्रा**ड्** |
