## Demonstratives (This / That)

| English | Male | Female | Neuter |
|---------|------|--------|--------|
| **Who/What is this?** | एषः कः? | एषा का? | एतत् किम्? |
| **This is a ___** | एषः ग्रन्थः (अस्ति) | एषा बालिका (अस्ति) | एतत् पुस्तकम् (अस्ति) |
| **Who/What is that?** | सः कः? | सा का? | तत् किम्? |
| **That is a ___** | सः बालकः (अस्ति) | सा बालिका (अस्ति) | तत् पुस्तकम् (अस्ति) |

## Location & Direction

| English | Sanskrit | Transliteration |
|---------|--------|----------------|
| ___ is here | वृक्षः **अत्र** अस्ति | vṛkṣaḥ atra asti |
| ___ is there | महानसम् **तत्र** अस्ति | mahānasam tatra asti |
| ___ is somewhere else | पर्वतः **अन्यत्र** अस्ति | parvataḥ anyatra asti |
| ___ is below ___ | भवनस्य **अधः** यानम् अस्ति | bhavanasya adhaḥ yānam asti |
| ___ is everywhere | ईशः **सर्वत्र** अस्ति | īśaḥ sarvatra asti |
| ___ is at one place | बालकाः **एकत्र** सन्ति | bālakāḥ ekatra santi |
| ___ is ahead | पाठशाला **अग्रे** अस्ति | pāṭhaśālā agre asti |
| Where is ___? | पाठशाला **कुत्र** अस्ति? | pāṭhaśālā kutra asti? |
