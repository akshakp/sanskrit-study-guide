# Nouns & Cases (शब्दरूपाणि)

## Inflection (विभक्ति)

**विभक्ति indicates the relationship of nouns with a verb or with other nouns.** They serve as grammatical links that convey the role of a noun such as subject, object, instrument, recipient, source, possession, location, and address.

---

## अकारान्त पुल्लिङ्ग विभक्ति-सारणी

Declension table for masculine nouns ending in **-a** (like राम, देव):

| विभक्तिः      | Question                    | Function                     | एकवचनम् | द्विवचनम्  | बहुवचनम् |
| ------------- | --------------------------- | ---------------------------- | ------- | ---------- | -------- |
| **प्रथमा**    | कः? का? किम्? (Who? What?)  | Subject (कर्ता)              | देवः    | देवौ       | देवाः    |
| **द्वितीया**  | किम्? कम्? (Whom? What?)    | Object (कर्म)                | देवम्   | देवौ       | देवान्   |
| **तृतीया**    | केन? (By what/whom?)        | Instrument (करण)             | देवेन   | देवाभ्याम् | देवैः    |
| **चतुर्थी**   | कस्मै? (For whom?)          | Recipient (संप्रदान)         | देवाय   | देवाभ्याम् | देवेभ्यः |
| **पञ्चमी**    | कस्मात्? (From what/where?) | Source (अपादान)              | देवात्  | देवाभ्याम् | देवेभ्यः |
| **षष्ठी**     | कस्य? (Whose?)              | Relation/Possession (संबन्ध) | देवस्य  | देवयोः     | देवानाम् |
| **सप्तमी**    | कुत्र? कदा? (Where? When?)  | Location (अधिकरण)            | देवे    | देवयोः     | देवेषु   |
| **सम्बोधनम्** | हे! (O!)                    | Addressee (श्रोता)           | हे देव  | हे देवौ    | हे देवाः |

## Sentence Analysis Example

> **हे यज्ञेश! प्रातःकाले मुनिवरस्य आश्रमे शिष्यः मोक्षाय कण्ठेन ग्रन्थात् श्लोकं रटति।**
>
> _O Yajñeśa! In the morning, at the great sage's hermitage, the disciple recites a verse from the scripture with his throat for liberation._

| Word       | Indicates  | विभक्तिः               |
| ---------- | ---------- | ---------------------- |
| हे यज्ञेश  | addressee  | **सम्बोधन** (श्रोता)   |
| प्रातःकाले | time       | **सप्तमी** (अधिकरण)    |
| मुनिवरस्य  | possession | **षष्ठी** (संबन्ध)     |
| आश्रमे     | location   | **सप्तमी** (अधिकरण)    |
| शिष्यः     | subject    | **प्रथमा** (कर्ता)     |
| मोक्षाय    | recipient  | **चतुर्थी** (संप्रदान) |
| कण्ठेन     | instrument | **तृतीया** (करण)       |
| ग्रन्थात्  | source     | **पञ्चमी** (अपादान)    |
| श्लोकं     | object     | **द्वितीया** (कर्म)    |

**Verb (क्रिया):** रटति

## णत्व नियम (Ṇatva Rule)

!!! warning "When does this apply?"
    This rule applies to: - **Third inflection singular** (तृतीया विभक्ति एकवचन) - **Sixth inflection plural** (षष्ठी विभक्ति बहुवचन)

### Rule Condition

"**न (na)**" is immediately after **र्, ष्, ऋ,** or **ॠ** — OR — one of the following is in between:

- Ha, Va, Ya (ह, व, य)
- Any vowel (स्वर)
- Consonant from K/Ku group (क्, ख्, ग्, घ्, ङ्)
- Consonant from P/Pu group (प्, फ्, ब्, भ्, म्)

### Examples

### तृतीया एकवचन (3rd Case Singular)

| Word     | तृतीया एकवचन | Breakdown                             | णत्व Result   |
| -------- | ------------ | ------------------------------------- | ------------- |
| रामः     | रामेन        | र् + आ + म् + ए + न                   | **रामेण**     |
| नृपः     | नृपेन        | न् + ऋ + प् + ए + न                   | **नृपेण**     |
| आम्रः    | आम्रेन       | आ + म् + र् + ए + न                   | **आम्रेण**    |
| कूपः     | कूपेन        | क् + ऊ + प् + ए + न                   | N/A           |
| परिश्रमः | परिश्रमेन    | प् + र् + इ + श् + र् + म् + ए + न    | **परिश्रमेण** |
| गर्दभः   | गर्दभेन      | ग् + अ + र् + <del>द्</del> + अ + भ् + ए + न | N/A           |

### षष्ठी बहुवचन (6th Case Plural)

| Word     | षष्ठी बहुवचन | Breakdown                                   | णत्व Result      |
| -------- | ------------ | ------------------------------------------- | ---------------- |
| रामः     | रामानाम्     | र् + आ + म् + आ + न + आ + म्                | **रामाणाम्**     |
| नृपः     | नृपानाम्     | न् + ऋ + प् + आ + न + आ + म्                | **नृपाणाम्**     |
| आम्रः    | आम्रानाम्    | आ + म् + र् + आ + न + आ + म्                | **आम्राणाम्**    |
| कूपः     | कूपानाम्     | क् + ऊ + प् + आ + न + आ + म्                | N/A              |
| परिश्रमः | परिश्रमानाम् | प् + र् + इ + श् + र् + म् + आ + न + आ + म् | **परिश्रमाणाम्** |
| गर्दभः   | गर्दभानाम्   | ग् + अ + र् + <del>द्</del> + भ् + अ + न् + आ + म् | N/A              |

!!! tip "Why no Ṇatva in गर्दभ?"
    In **गर्दभ**, the र् is followed by **द्** (a consonant from the **तु group**, not कु or पु group), and **द्** is not ह, व, or य. So the condition is **not met**.
