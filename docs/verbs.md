# Verbs (क्रियापदम्)

A verb describes an **action**, an **occurrence**, or a **state of being**.

---

## Verb Forms: अर्थ (Intention) and काल (Tense)

### 4 अर्थ — What is the speaker's intention?

| अर्थ | Meaning |
|------|---------|
| **आज्ञार्थ** | Command |
| **विध्यर्थ** | Request / Suggestion / Prescription |
| **आशीर्वादार्थ** | Blessings |
| **क्रियातिपत्त्यर्थ** | Hypothetical action |

### 6 काल — When is the action?

| Past Tense | Present Tense | Future Tense |
|-----------|---------------|--------------|
| **परोक्ष** — Before one's birth | | **सामान्य** |
| **ह्यस्तन** — Since birth till yesterday midnight | | **श्वस्तन** |
| **अद्यतन** — Since start of day till present | | |

## Types of Verbs (क्रियापद)

### Based on Suffix (प्रत्यय)

- **परस्मैपदी** — For others
- **आत्मनेपदी** — For self
- **उभयपदी** — Both

### Based on Number of Objects (कर्म)

| Type | Objects | Pattern | Examples |
|------|---------|---------|----------|
| **अकर्मक** (Intransitive) | 0 | कर्ता + क्रियापद | वृक्षः फलति, बालः हसति |
| **सकर्मक** (Transitive) | 1 | कर्ता + कर्म + क्रियापद | रामः फलम् खादति, व्यासः वेदान् पठति |
| **द्विकर्मक** (Ditransitive) | 2 | कर्ता + कर्म + कर्म + क्रियापद | सः गुरुम् प्रश्नं पृच्छति |

!!! note "Ditransitive Verbs"
    - **What?** = मुख्य कर्म (main object) → **द्वितीया**
    - **Whom?** = गौण कर्म (secondary object) → **चतुर्थी**

## Formation Rules for Parasmaipada Verb Forms

| Condition | गुण Change | Example |
|-----------|------------|---------|
| **Suffix starts with अ** | Merge with गण-प्रत्यय अ | नम् + अ + अन्ति = **नमन्ति** |
| **Suffix starts with म् / व** | गण-प्रत्यय अ → आ | नम् + अ + मि = नम् + आ + मि = **नमामि** |
| **उपधा = इ, उ, ऋ, लृ** | इ ➞ ए, उ ➞ ओ, ऋ ➞ अर्, लृ ➞ अल् | चित् → चेत, घुष् → घोष, वृष् → वर्ष |
| **उपधा = अ, आ, ई, ऊ, ॠ or व्यञ्जन** | No गुण change | अर्च् → अर्च, क्रीड् → क्रीड |
| **धातु ends with इ, ई, उ, ऊ, ऋ, ॠ, लृ + गण-प्रत्यय अ** | इ, ई ➞ ए; उ, ऊ ➞ ओ; ऋ, ॠ ➞ अर्; लृ ➞ अल् | क्षि + अ = क्षे + अ; भू + अ = भो + अ |

## संधि विशिष्ट नियम (Special Conjunction Rule)

When धातु ends with **ए, ऐ, ओ, औ** and गण-प्रत्यय = **अ**:

| Vowel | Changes To |
|-------|-----------|
| **ए** | अय् |
| **ऐ** | आय् |
| **ओ** | अव् |
| **औ** | आव् |

### Examples

| धातु | Process | Result |
|------|---------|--------|
| **क्षि** + अ | क्ष् + इ + अ → क्ष् + ए + अ → क्ष् + अय् + अ | **क्षय** |
| **भू** + अ | भ् + उ + अ → भ् + ओ + अ → भ् + अव् + अ | **भव** |
| **द्रु** + अ | द्र + उ + अ → द्र + ओ + अ → द्र + अव् + अ | **द्रव** |
| **ध्यै** + अ | ध्य् + ऐ + अ → ध्य् + आय् + अ | **ध्याय** |
| **सृ** + अ | स् + ऋ + अ → स् + अर् + अ | **सर** |

!!! question "Why does सृ become सर but द्रु become द्रव?"
    When **ृ** is attached to a consonant, it sounds like **ऋ**. But **ु** sounds like **र् + उ**, and **ू** sounds like **र् + ऊ**.

## आदेशयुक्त धातु (Ordered Roots)

For some roots, when गण-प्रत्यय **अ** is applied, the root itself changes instead of following normal rules. This is called **आदेश** (order).

| धातु | Changes To | Meaning | Form |
|------|-----------|---------|------|
| **गम्** | गच्छ् | To go | गच्छति |
| **स्था** | तिष्ठ | To stand | तिष्ठति |
| **दृश्** | पश्य | To see | पश्यति |
| **पा** | पिब | To drink | पिबति |
| **दा** | यच्छ | To give | यच्छति |
| **ऋ** | ऋच्छ | To reach | ऋच्छति |
| **ध्मा** | धम | To blow | धमति |
| **घ्रा** | जिघ्र | To smell | जिघ्रति |
| **म्ना** | मन | To think | मनति |
| **यम्** | यच्छ | To restrain | यच्छति |
| **दंश्** | दश | To bite | दशति |

## विशिष्ट धातु-प्रयोग-नियमाः (Special Verb Usage Rules)

### गत्यर्थक धातु (Verbs of Motion)

When using verbs of motion (e.g., **गम्, रु, चर्**), the **destination** takes **द्वितीया विभक्ति** instead of सप्तमी.

!!! example
    - भक्ताः **मन्दिरं** गच्छन्ति (NOT मन्दिरे)
    - वयं देशाद् **देशान्** चरामः (NOT देशेषु)

### दा आदि धातवः (Verbs of Giving)

- The **thing being given** (मुख्य कर्म) → **द्वितीया विभक्ति**
- The **recipient** (गौण कर्म) → **चतुर्थी विभक्ति**

!!! example
    - नृपः **ब्राह्मणेभ्यः** **धनं** यच्छति
    - श्रीकृष्णः **ब्राह्मणाय** **दक्षिणां** यच्छति

## Rules of Writing in Sanskrit

### Word Order

The order of words does **not** change the meaning.

```
रामः सूर्यं नमति |
सूर्यं रामः नमति |
नमति रामः सूर्यं |
```
All are correct and have the same meaning.

### When a word ends in म्

| Condition | Change | Example |
|-----------|--------|---------|
| Followed by Consonant | म् → Anusvāra (ं) | रामम् नमामि = **रामं नमामि** |
| Followed by Vowel | म् remains (can join) | रामः भक्तम् अवति = रामः **भक्तमवति** |
| End of Sentence | म् remains | नमामि रामम् |

### Sandhi 1-3 Rule

A word ends with the **1st, 2nd, 3rd, or 4th letter** of a consonant group (क्, च्, ट्, त्, प्):

| Condition | Change | Before | After |
|-----------|--------|--------|-------|
| Followed by Vowel OR Ghoṣa consonant | letter → 3rd letter | स्वर्गात् अमराः | स्वर्गा**द्** अमराः |
| Followed by Aghoṣa consonant | letter → 1st letter | पुरुषः ग्रन्थात् पठति | (no change) |
| End of Sentence | letter → 1st or 3rd | तरति सम्राट् | तरति सम्रा**ट्** or सम्रा**ड्** |
