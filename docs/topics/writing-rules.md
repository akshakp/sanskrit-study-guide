# Rules of Writing in Sanskrit

## Word Order

The order of words does **not** change the meaning.

```
रामः सूर्यं नमति |
सूर्यं रामः नमति |
नमति रामः सूर्यं |
```

All are correct and have the same meaning.

---

## परसवर्ण नियम (Reciprocal Law)

This rule explains how an **anusvāra (ं)** changes before grouped consonants.

**Rule:**

- If the sound after anusvāra belongs to a consonant group → replace the anusvāra with the nasal letter of that same group
- If the following sound is not grouped → keep the anusvāra as a bindu (ं)

| Following Group | Anunāsik  | Example                |
| --------------- | --------- | ---------------------- |
| कु group        | ङ्        | शंकर → **शङ्कर**       |
| चु group        | ञ्        | संजय → **सञ्जय**       |
| टु group        | ण्        | मार्कंड → **मार्कण्ड** |
| तु group        | न्        | कंदर्प → **कन्दर्प**   |
| पु group        | म्        | अंबरीष → **अम्बरीष**   |
| Not grouped     | ं remains | संसार, हंस, संस्कार    |

## When a word ends in म्

| Condition             | Change                | Example                              |
| --------------------- | --------------------- | ------------------------------------ |
| Followed by Consonant | म् → Anusvāra (ं)     | रामम् नमामि = **रामं नमामि**         |
| Followed by Vowel     | म् remains (joins following vowel) | रामः भक्तम् अवति = रामः **भक्तमवति** |
| End of Sentence       | म् remains            | नमामि रामम्                          |

## Sandhi 1-3 Rule

A word ends with the **1st, 2nd, 3rd, or 4th letter** of a consonant group (क्, च्, ट्, त्, प्):

| Condition                            | Change              | Before                | After                           |
| ------------------------------------ | ------------------- | --------------------- | ------------------------------- |
| Followed by Vowel OR Ghoṣa consonant | letter → 3rd letter | स्वर्गात् अमराः       | स्वर्गा**द्** अमराः             |
| Followed by Aghoṣa consonant         | letter → 1st letter | पुरुषः ग्रन्थात् पठति | (no change)                     |
| End of Sentence                      | letter → 1st or 3rd | तरति सम्राट्          | तरति सम्रा**ट्** or सम्रा**ड्** |

## Visarga Sandhi (विसर्गसन्धिः)

Visarga Sandhi occurs when **विसर्गः ( ः )** comes next to a vowel or consonant and changes according to the surrounding sounds.

> **Important**
>
> - When an **अघोष consonant** follows the visarga, mainly look at the letter **after ः**.
> - In the other rules, you may need to check both the vowel **before ः** and the sound **after ः**.

### Visarga Sandhi Rules

| Rule | Before ः | After ः | Result | AARSH Example |
|---|---|---|---|---|
| **1.1** | Any vowel | क्, ख्, प्, फ् | ः remains | मुनिः कपिलो मे विभूतिः → मुनिः कपिलो मे विभूतिः |
| **1.2** | Any vowel | च्, छ् | ः → श् | रवेः छविः → रवेश्छविः |
| **1.3** | Any vowel | ट्, ठ् | ः → ष् | नृपतेः टङ्कारः → नृपतेष्टङ्कारः |
| **1.4** | Any vowel | त्, थ् | ः → स् | गङ्गायाः तीरे आश्रमः → गङ्गायास्तीरे आश्रमः |
| **1.5** | Any vowel | श्, ष्, स् | ः remains OR matching श् / ष् / स् | ब्राह्मणाः शास्त्रं पठन्ति → ब्राह्मणाः शास्त्रं पठन्ति / ब्राह्मणाश्शास्त्रं पठन्ति |
| **2.1** | अ | अ | अः → ओऽ | दासः अस्मि → दासोऽस्मि |
| **2.2** | अ | घोष consonant | अः → ओ | देवः जयति → देवो जयति |
| **2.3** | अ | vowel other than अ | ः disappears | सन्तोषः एव परं निधानम् → सन्तोष एव परं निधानम् |
| **3.1** | आ | vowel | ः disappears | भक्ताः आगच्छन्ति गृहम् → भक्ता आगच्छन्ति गृहम् |
| **3.2** | आ | घोष consonant | ः disappears | मेघाः वर्षन्ति → मेघा वर्षन्ति |
| **4.1** | vowel other than अ / आ | vowel | ः → र् | ऋषेः अगस्त्यस्य आश्रमः → ऋषेरगस्त्यस्य आश्रमः |
| **4.2** | vowel other than अ / आ | घोष consonant | ः → र् | मुनिः भजते श्रीहरिम् → मुनिर्भजते श्रीहरिम् |
| **4.3** | vowel other than अ / आ | र् | र् disappears; previous vowel becomes long | हरिः रक्षति → हरिर् रक्षति → हरी रक्षति |
| **5.1** | सः / एषः | अ | ओऽ | सः अहम् → सोऽहम् |
| **5.2** | सः / एषः | anything other than अ | ः disappears | एषः आचार्यः → एष आचार्यः |
| **6.1** | भोः | vowel / घोष consonant | ः disappears | भोः अर्जुन! → भो अर्जुन! |
| **6.2** | भोः | अघोष consonant | ः remains | भोः कृष्ण! → भोः कृष्ण! |
| **7** | Any | End of sentence | ः remains | देवम् अर्चति तव तातः। |
| **8** | र्-स्थानिक ः | vowel / घोष consonant | ः → र् | पुनः अपि → पुनरपि |
