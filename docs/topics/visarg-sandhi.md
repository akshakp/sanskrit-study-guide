# Visarga Sandhi (विसर्गसन्धिः)

Visarga Sandhi occurs when **विसर्गः ( ः )** comes next to a vowel or consonant and changes according to the surrounding sounds.

> **Important**
>
> - When an **अघोष consonant** follows the visarga, mainly look at the letter **after ः**.
> - In the other rules, you may need to check both the vowel **before ः** and the sound **after ः**.

---

## Quick Decision Strategy

1. If an **अघोष consonant** follows → **Rule 1**
2. If the form is **अः** → **Rule 2**
3. If the form is **आः** → **Rule 3**
4. If a vowel other than **अ / आ** comes before ः → **Rule 4**
5. If the word is **सः / एषः** → **Rule 5**
6. If the word is **भोः** → **Rule 6**
7. If ः is at the **end of a sentence** → **Rule 7**
8. If ः is **र्-स्थानिक विसर्ग** → **Rule 8**

## Important Concepts and Exceptions

### स्-स्थानिक विसर्ग

A visarga that stands in place of an original **स्** is called **स्-स्थानिक विसर्ग**. Rules **1–7** generally deal with this type.

Examples from the lesson include forms such as **देवः, देवाः, हरिः, हरेः, भानुः, भानोः, पठतः, जपथः, अतः, ततः, इतः, कुतः**.

### र्-स्थानिक विसर्ग

A visarga that stands in place of an original **र्** is called **र्-स्थानिक विसर्ग**.

Examples from the lesson include:

- स्वर् → स्वः
- अन्तर् → अन्तः
- प्रातर् → प्रातः
- पुनर् → पुनः

Rule 8 restores this visarga to **र्** under the conditions shown in the Master Summary Table.

**Example:** पुनः + अपि → **पुनरपि**

### Rule 1.5 — Optional Change

Before **श्, ष्, स्**, the visarga may remain **ः** or change to the corresponding **श्, ष्, स्**.

**Example:**

ब्राह्मणाः शास्त्रं पठन्ति  
or  
ब्राह्मणाश्शास्त्रं पठन्ति

### Rule 4.3 — Special Case Before र्

When the visarga becomes **र्** and the following sound is also **र्**, the first **र्** disappears and the preceding vowel becomes long.

**Example:**

हरिः रक्षति  
→ हरिर् रक्षति  
→ **हरी रक्षति**

# Memory Shortcut

## If an अघोष Consonant Follows

- **क ख प फ → ः**
- **च छ → श्**
- **ट ठ → ष्**
- **त थ → स्**
- **श ष स → ः or matching श् / ष् / स्**

A quick pattern:

- **च → श**
- **ट → ष**
- **त → स**

---

## If a Vowel or घोष Consonant Follows

Look at the vowel before the visarga:

- **अः → ओ / लोप**
- **आः → लोप**
- **Other vowel + ः → र्**

Then remember the special forms:

- **सः / एषः**
- **भोः**
- **Sentence-ending ः**
- **र्-स्थानिक ः**

# Worked Example — रवेश्छविः

Start with:

**रवेः + छविः**

The letter after the visarga is **छ्**.

Apply **Rule 1.2**:

**ः + छ् → श्**

Therefore:

**रवेः + छविः**  
→ रवेश् + छविः  
→ **रवेश्छविः**

**Meaning:** the radiance of the sun.
